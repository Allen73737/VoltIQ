# VoltIQ Deployment Guide

This repo is ready for:

- Backend: Render Web Service
- Database: Neon PostgreSQL
- Frontend: Vercel Vite deployment

## What Is Left To Do

The code is ready. The only remaining steps require your personal hosting accounts:

1. Push this project to GitHub.
2. Create/sync the Render web service from `render.yaml`.
3. Deploy the Vercel project from the `frontend` folder.
4. Add the final production URLs as environment variables on both platforms.

## Deploy Backend On Render

Render files added:

- `render.yaml`
- `backend/Dockerfile`
- `backend/.env.example`

Steps:

1. Push this repository to GitHub.
2. Open Render Dashboard.
3. Create a new Web Service or Blueprint from the GitHub repo.
4. Render will create `voltiq-backend`.
5. Add these environment variables:

```env
DATABASE_URL=postgresql://YOUR_NEON_USER:YOUR_NEON_PASSWORD@YOUR_NEON_HOST/YOUR_NEON_DATABASE?sslmode=require
JWT_SECRET=VoltIQUltraPremiumEnterpriseJwtSecretKeyForHS256ChangeMe12345
JWT_EXPIRATION_MS=86400000
ENERGY_TARIFF_PER_KWH=9.35
CORS_ALLOWED_ORIGINS=http://localhost:5173
```

After Vercel is deployed, update `CORS_ALLOWED_ORIGINS` to:

```text
http://localhost:5173,https://YOUR-VERCEL-PROJECT.vercel.app
```

After deployment, your backend API will look like:

```text
https://voltiq-backend.onrender.com
```

Health check:

```text
https://voltiq-backend.onrender.com/actuator/health
```

## Deploy Frontend On Vercel

Vercel files added:

- `frontend/vercel.json`
- `frontend/.env.example`

Steps:

1. Open Vercel Dashboard.
2. Import the same GitHub repo.
3. Set the project root directory to:

```text
frontend
```

4. Vercel should detect Vite automatically.
5. Add this environment variable:

```text
VITE_API_URL=https://voltiq-backend.onrender.com/api
```

6. Deploy.

The `frontend/vercel.json` file rewrites all frontend routes to `index.html`, so direct links like `/demo`, `/register`, and `/app` work after refresh.

## Final Production Wiring

After Vercel gives you the final frontend URL, go back to Render and update:

```text
CORS_ALLOWED_ORIGINS=https://YOUR-VERCEL-PROJECT.vercel.app
```

You can include local development too:

```text
CORS_ALLOWED_ORIGINS=http://localhost:5173,https://YOUR-VERCEL-PROJECT.vercel.app
```

Then redeploy the Render backend.

## Important Notes

- Neon provides PostgreSQL as `DATABASE_URL`; the backend converts this automatically for Spring JDBC and preserves `sslmode=require`.
- `JWT_SECRET` is generated by Render through the Blueprint.
- Vercel requires frontend build-time variables to start with `VITE_`, so the API URL is `VITE_API_URL`.
